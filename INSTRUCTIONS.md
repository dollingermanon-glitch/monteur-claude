# AvatarHype : installation

AvatarHype s'installe uniquement sur **macOS ou Windows x64**, depuis Claude Code sur ton ordinateur (pas depuis une session cloud).

1. Sur ton Mac, ouvre l'app Claude (onglet Claude Code) et ouvre un dossier de projet permanent.
2. Sur AvatarHype Academy, génère un nouveau lien d'installation (les liens expirent au bout de 15 minutes).
3. Colle le lien dans Claude Code avec la demande : « Installe et connecte AvatarHype dans ce dossier en suivant les instructions officielles. »
4. Accepte l'autorisation d'exécuter le script quand Claude te la demande.
